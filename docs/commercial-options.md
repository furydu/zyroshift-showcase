# Commercial options

ZyroShift can be discussed as a project acquisition, a source license or a starting point for custom development. Scope and pricing are quoted after understanding the intended use.

| Option | Scope to agree |
| --- | --- |
| Project acquisition | Delivered code version, documentation, owned brand assets, domain inclusion, handover support and any exclusivity |
| Source license | Permitted deployments, modification rights, redistribution limits, updates and support |
| Custom implementation | Branding, screens, provider integration, content structure, milestones and acceptance criteria |

## Delivery boundaries

- A code/design sale does not automatically transfer a provider account, API access or negotiated commercial arrangement.
- The buyer supplies valid provider credentials and satisfies the provider's eligibility requirements. Any account transfer requires separate confirmation.
- Domain and brand assets are included only when agreed and transferable.
- Current source, documented setup and implementation assistance can be scoped separately.
- Live trading records, private keys, production secrets and customer data are excluded from a public showcase.
- Prior public source availability and any previous licenses must be disclosed before agreeing to exclusivity.

The earlier source revision and the newer local affiliate extension have different scopes. A delivery should identify its exact source revision and explicitly list any additional modules.
